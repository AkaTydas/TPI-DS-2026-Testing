# TPI-DS-2026-Testing

Repositorio de trabajo y staging para el desarrollo del **Módulo 9: Reservas de Viajes (Grupo 8)** correspondiente a la cátedra de Desarrollo de Software 2026.

## Responsabilidades del Módulo (M9)
- Gestión del ciclo de vida de reservas de viajes (creación, modificación, cancelación y consulta).
- Control de ventanas de anticipación mínima y máxima.
- Orquestación con M2 (Clientes), M4 (Ubicación), M7 (Tarifas) y M8 (Notificaciones).
- Activación en M5 (Solicitud y Despacho) de forma idempotente para evitar duplicación de solicitudes.
